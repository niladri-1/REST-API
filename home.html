🚀 REST API Documentation

User Management System

✓ Server Running

📋 Overview

Base URL: https://curdapi-ycmy.onrender.com

API Version: 1.0.0

Content-Type: application/json

This is a RESTful API for managing users. It provides endpoints to create, read, update, and delete user records.

🔗 Available Endpoints

GET /users
Retrieve all users from the database.
Request Example:
GET https://curdapi-ycmy.onrender.com/users
Response Example (200 OK):
[
  {
    "firstName": "John",
    "lastName": "Doe",
    "age": 25,
    "id": "a7b8c9d0-1234-5678-90ab-cdef12345678"
  },
  {
    "firstName": "Jane",
    "lastName": "Smith",
    "age": 30,
    "id": "b8c9d0e1-2345-6789-01bc-def123456789"
  }
]
POST /users
Create a new user. The server will automatically generate a unique ID using UUID v4.
Request Body:
{
  "firstName": "John",
  "lastName": "Doe",
  "age": 25
}
Response Example (200 OK):
"John is added"
GET /users/:id
Retrieve a specific user by their unique ID.
Request Example:
GET https://curdapi-ycmy.onrender.com/users/a7b8c9d0-1234-5678-90ab-cdef12345678
Response Example (200 OK):
{
  "firstName": "John",
  "lastName": "Doe",
  "age": 25,
  "id": "a7b8c9d0-1234-5678-90ab-cdef12345678"
}
PATCH /users/:id
Update an existing user's information. You can update one or more fields (firstName, lastName, age).
Request Body (partial update):
{
  "firstName": "Jonathan",
  "age": 26
}
Response Example (200 OK):
"a7b8c9d0-1234-5678-90ab-cdef12345678 has been updated!"
DELETE /users/:id
Delete a user from the database by their unique ID.
Request Example:
DELETE https://curdapi-ycmy.onrender.com/users/a7b8c9d0-1234-5678-90ab-cdef12345678
Response Example (200 OK):
"User Id: a7b8c9d0-1234-5678-90ab-cdef12345678 deteled from DB!"

💡 Testing the API

Tools you can use:

  • Postman - Popular API testing tool
  • Thunder Client - VS Code extension
  • cURL - Command line tool
  • Browser - For GET requests only
Example cURL Command:
# Create a new user
curl -X POST https://curdapi-ycmy.onrender.com/users \
  -H "Content-Type: application/json" \
  -d '{"firstName":"John","lastName":"Doe","age":25}'

⚠️ Important Notes

  • All data is stored in-memory. Restarting the server will clear all users.
  • User IDs are automatically generated using UUID v4.
  • All requests expecting JSON should include the header: Content-Type: application/json
  • The PATCH endpoint allows partial updates - you don't need to send all fields.
  • There's a typo in the delete response: "deteled" instead of "deleted" 😊
