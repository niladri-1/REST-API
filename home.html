REST API - User Management

Base URL: https://curdapi-ycmy.onrender.com

GET /users

Get all users from the database

URL: https://curdapi-ycmy.onrender.com/users

Response: Array of user objects

POST /users

Create a new user

URL: https://curdapi-ycmy.onrender.com/users

Body:

{
  "firstName": "John",
  "lastName": "Doe",
  "age": 25
}

Response: "John is added"

GET /users/:id

Get a specific user by ID

URL: https://curdapi-ycmy.onrender.com/users/uuid

Response: Single user object

PATCH /users/:id

Update user information

URL: https://curdapi-ycmy.onrender.com/users/uuid

Body:

{
  "firstName": "Jonathan",
  "age": 26
}

Response: "uuid has been updated!"

DELETE /users/:id

Delete a user by ID

URL: https://curdapi-ycmy.onrender.com/users/uuid

Response: "User Id: uuid deteled from DB!"
